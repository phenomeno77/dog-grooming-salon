# Pfotenstyle by Dani — Redesign-Demo

Nuxt 4 + Tailwind CSS v4 + PrimeVue (unstyled) Template als Akquise-Beispiel für den Inhaber von
[pfotenstyle.at](https://www.pfotenstyle.at/home.html).

Alle Texte sind 1:1 von der bestehenden Seite übernommen, Bilder sind Platzhalter
(`ImgPlaceholder.vue`) — echte Fotos können später einfach eingesetzt werden.

## Setup

```bash
npm install
npm run dev
```

## Fertige Seiten

- `/` – Home (Hero, Intro, Gifts & Services, Tier-Balance, Team-Teaser)
- `/ueber-uns` – About (Produktphilosophie, Team: Dani, Petra, Anna)
- `/leistungen` – Services & Preisliste
- `/oeffnungszeiten` – Öffnungszeiten
- `/kontakt` – Kontakt (Adresse, Telefonnummern, kleines Kontaktformular mit PrimeVue Toast)

## Noch offen

- `/impressum`, `/agb`, `/datenschutz` – folgen als Nächstes (Footer/Nav verlinken bereits dorthin)
- Echte Fotos statt Platzhalter
- Ggf. echtes Backend/E-Mail-Versand für das Kontaktformular (aktuell nur Demo-Toast)

## Design

Alpine-/Hundesalon-Palette (Moos-Grün, Sand, Lehm-Orange, Gold), Fraunces als Display-Schrift,
Work Sans als Fließtext, IBM Plex Mono für Preis-/Eyebrow-Labels. Signature-Element: "Tag-Card" —
an die handgefertigten Leder-/Paracord-Halsband-Anhänger angelehnte Karten mit Lochung und
Stitch-Divider für Trennlinien.
